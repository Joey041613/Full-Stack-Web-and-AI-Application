# Full-Stack-Web-and-AI-Application
This project is aligned with the AP Computer Science Principles curriculum. It covers 5 core big ideas: Creative Development, Data, Algorithms & Programming, Computer Systems & Networks, and Impact of Computing.
The learning system supports spiral practice, project-based learning and flexible elective tracks (including AI, robotics, cybersecurity). We integrate computational thinking into full-stack web and AI application development, and meet the assessment standards of AP CSP exam.
